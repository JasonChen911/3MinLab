# 3MinLab · 活动现场模拟器（独立版）

独立网页位于本仓库的 `standalone-game/`，不会写入或启动策划网页。`src/engine` 是从原项目 `src/simulation` 提取的概率引擎副本，去除了原策划项目专用的快照转换器；小游戏可以单独构建和运行。

## 本地运行

```powershell
npm install
npm test
npm run build
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 8795
```

访问 http://127.0.0.1:8795/ 。浏览器需要支持 WebGL。

## 操作

1. 选择活动场景，或导入 3MinLab 导出的“完整活动备份 JSON”。导入只提取活动信息，不会写回原项目。
2. 中央工具栏选择设施，拖入三维场地或点击场地放置。绿色预览表示可放置，黄色表示有提醒，红色表示预算、边界或占地冲突。工具栏可拖动、收起、搜索和筛选。
3. 拖动设施可移动；选中后可旋转、复制或删除。R 旋转，Delete 删除，Ctrl+C/V 复制粘贴，Ctrl+Z/Y 撤销恢复，Q 或 Esc 退出放置模式。拖动空白处旋转镜头，滚轮缩放，中键或空格拖动平移，WASD 或方向键移动镜头。
4. 查看场地目标、预算、碰撞检查和概率假设，修改人数、工作人员和流程。可调整草地、广场和跑道地面。
5. 开始模拟；可暂停、单步、调节速度和采取干预。暂停后可修改场地，再继续模拟；现有进度和突发事件保留，设施容量和通行能力会重新计算。
6. 布局与模拟进度自动保存在当前浏览器；“保存”可手动保存。不同浏览器不会自动同步。

概率参数默认属于系统演示假设，仅用于压力测试，不代表真实世界事件发生率。

## 当前边界

- 导入采用文件方式；原网页入口和自动跳转尚未接入，因为本次要求不修改原项目。
- 流程、人数、预算、日期、工作人员数量会从完整备份提取；复杂的物资清单和应急预案尚未映射成三维对象。
- 人物使用聚合显示（最多约 80 个），统计数据仍由概率引擎计算全部参与者。
- 路径规划为二维网格避障并优先选择道路，尚无多人互相避让与专业赛事计分。
- 浏览器预览可以打开，但三维画面和全部交互尚未通过自动化浏览器测试。
- 模拟结果不会自动回写 3MinLab 正式策划方案。
