## 安全与数据边界

- 不变更原始背景图、真实活动照片、Icon/SVG 资源，不重写赛事计分与预算算法。
- 复用工作台 `tables`，新增兼容字段。报名状态与签到字段分离，支出与计划金额分离；历史案例是确认时的独立文本快照。
- 旧浏览器 Key 自动清除。推荐在服务端 `.env.local` 设置 `AI_API_KEY`；仍兼容 `DEEPSEEK_API_KEY`。临时 Key 只存在后端进程内存，配置时必须经本机请求提交，因此该次请求仍可在本机开发者工具看到。业务请求、状态接口、公开源码和非秘密配置文件均不包含 Key。
- 非秘密配置保存在忽略的 `ai-config.local`；服务仅面向本机单用户。配置/新任务路由限制回环客户端，检查 Host/Origin，拒绝 URL 内嵌凭据。
- 所有统计从真实表或真实仿真计算得到；缺失实际指标显示未知。仿真使用假设模型，不代表实际风险概率。人员利用率是离散分钟状态采样值。
